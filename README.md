# 妖币末日狙击系统 · 模拟盘

初始模拟资金 **200 U**，逐仓，固定 **10×**。一次只持有一笔空单，空仓时取当前账面资金的 50% 作为保证金。首笔是 100 U 保证金和 1,000 U 名义仓位。默认自动筛选 Binance 正在交易的全部 USDT 永续合约，不需要交易所密钥。

空仓时每根 15 分钟 K 线收盘后扫描一次。先用收盘前采集的费率筛出候选，再对候选检查全部 K 线条件。同时出现多个信号时，按资金费率降序、合约代码升序选择一笔。持仓或等待成交时优先处理这笔仓位，退出后从下一根收盘 K 线恢复筛选。每日净结算按悉尼时间统计已发生的盈亏、手续费和资金费。

## 本地运行

需要 Python 3.12 或更新版本。进入项目目录后执行：

```powershell
python -m pip install -r requirements.txt
python server.py
```

打开 http://127.0.0.1:8000 。行情连接失败时面板会显示错误，已有账本保存在 `data/paper.sqlite3`。每个账本只运行一个进程。首次启动只用历史数据预热，等启动后的新收盘 K 线产生信号。

## GitHub Actions + Pages

把项目推到独立公开仓库的默认分支，在 Settings → Pages 将 Source 设为 GitHub Actions。到 Actions 手动运行 **Paper trading and Pages**，确认面板和公开行情状态。工作流会把模拟账本写入默认分支的 `paper-state.json`，因此默认分支需要允许这个仓库的 Actions 推送。不要在仓库中放交易所密钥。

工作流尝试每 5 分钟采集一次费率并处理已收盘的 15 分钟 K 线。若 GitHub 调度延迟到错过收盘前两分钟的采样窗，该根跳过新开仓。Runner 若无法访问 Binance，页面显示行情失败，已保存的账本继续保留。公开仓库的代码、模拟账本及页面均可公开读取。

## Render 部署

把本目录内容作为独立 GitHub 仓库提交，在 Render 创建 Blueprint 并关联仓库。它会读取 `render.yaml`，用 Docker 创建免费 Web Service。部署完成后，以 Render 控制台显示的 URL 打开面板。

这份 Blueprint 默认使用免费方案，适合打开页面时观察。空闲 15 分钟会休眠，休眠或重启会丢失本地账本。要 24 小时运行并保留账本，使用支持持久磁盘的实例，将磁盘挂载到 `/app/data`，保留 `STATE_DB=/app/data/paper.sqlite3`，实例数量保持为 1。面板和状态接口默认公开，只展示模拟账户数据。部署后先检查面板的行情状态，再判断该服务器能否访问 Binance 公开接口。

## 免费云主机或已有 Linux 主机

可以使用 Oracle Cloud Always Free 的 Linux 实例。免费机型受区域容量及闲置回收规则约束。开通后在云主机先执行 `curl -fsS https://fapi.binance.com/fapi/v1/time` 检查公开行情是否可达。安装 Docker 和 Compose 后，把项目目录上传到该主机，运行 `docker compose up -d --build`。Compose 会在主机重启后恢复服务，模拟账本保存在 Docker 卷。

面板默认只绑定云主机的本地端口。可以从电脑用 `ssh -L 8000:127.0.0.1:8000 用户名@云主机公网IP` 建立隧道，然后打开 http://127.0.0.1:8000 。请用实际主机 IP 和 SSH 用户名替换命令中的文字。

## 成交和风险模型

- 六项开仓条件全部在已收盘 K 线上计算。24 小时窗口要求 96 根连续 15 分钟 K 线。取最近一根同时满足长上影和缩量的 K 线确定止损。资金费率须有收盘前两分钟内的行情快照，缺失则不生成新单。
- 模拟卖出限价为下一根开盘价，只在该根最高价严格穿过限价时模拟成交。挂单仅有效一根 K 线。止损触发优先于同一根 K 线内的第二止盈。成交 K 线不以盘中最低价触发第二止盈，因为无法判断低点是否出现在开仓之后。
- 第一止盈要求收盘价从 MA20 上方或线上跌到线下，在下一根开盘以模拟市价买回一半，然后把剩余止损移到开仓价。保本价未覆盖手续费和滑点。
- `TP2_MODE=half_low` 默认表示信号时 24 小时最低价 × 0.5。`half_retracement` 表示最低价与最高价的中点，两种目标都在信号时冻结。
- 手续费默认开仓 0.02%、平仓 0.05%，平仓滑点默认 0.05%，可用 `PAPER_SLIPPAGE=0.005` 做 0.5% 的压力测试。模拟逐仓强平使用固定维持保证金率 0.5% 和 K 线成交价近似，入场时止损已落在强平线之外会取消挂单。已公布资金费按结算价计入逐仓余额。这些模型不复刻订单簿排队、交易所的精度过滤、真实标记价格强平或历史费率档位。
- 设置 `PAPER_SYMBOL` 可更换交易对。更改交易对、TP2 公式或费用后，使用新的 `STATE_DB`，原账本可独立保留。

## 历史回放

```powershell
python replay.py candles.csv
python replay.py candles.csv --settlements funding.csv --slippage 0.005
```

`candles.csv` 包含 timestamp、open、high、low、close、volume、funding_rate。时间戳为开盘时刻的 UTC 毫秒，费率为该根收盘时已知的费率，缺失可留空。不要把当前费率复制到历史 K 线。`funding.csv` 包含 time（UTC 毫秒）、rate、mark。省略结算文件时回放盈亏不含资金费现金流。输出 JSON 包含权益、持仓和最近 300 条模拟事件。
